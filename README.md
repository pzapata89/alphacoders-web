# Alphacoders - Streamlit

Aplicación básica en Streamlit con:

- Página principal: "Hola Mundo, soy Alphacoders".
- Página de privacidad.
- Navegación utilizando el sistema de páginas de Streamlit.

## Ejecutar

```bash
pip install -r requirements.txt
streamlit run app.py
```

Luego abre la URL indicada por Streamlit.

La página de privacidad estará disponible desde el menú de navegación de Streamlit y normalmente tendrá una ruta similar a:

`/privacidad`

dependiendo de la versión y configuración de Streamlit.
